# MyGame — 게임 컨셉 문서

> 학습 프로젝트로 만든 3인칭 프로토타입에 방향성을 부여하기 위한 컨셉 1페이지.
> AI(Claude)와 대화하며 톤·목표·씬 구성을 정리했다. (기획 초안 → 직접 검토·수정)

---

## 로그라인

**해질 무렵, 조용한 항구 마을. 마지막 배가 떠나기 전에 무언가를 마무리해야 한다.**

플레이어는 오랜만에 고향 항구로 돌아온 인물이 되어, 어둠이 완전히 내리기 전까지
마을을 걸어다니며 작은 일들을 처리한다. 전투도 실패도 없고, 시간과 분위기만 있다.

## 톤 & 레퍼런스

- **분위기**: 노스탤지어, 잔잔함, 약간의 쓸쓸함 (blue hour)
- **레퍼런스**: *A Short Hike*, *Journey* 의 이동감, *풍경이 주인공인* 워킹 심
- **비주얼**: 저녁 하늘(HDRI 스카이박스) + 따뜻한 가로등 + 낮은 채도의 바닥.
  현재 URP 포스트프로세싱(Bloom·비네트·색보정)이 이 톤을 만든다.

## 플레이어 목표 & 코어 루프

```
항구 도착  →  마을을 돌아다님  →  표시된 지점 3곳에서 상호작용
          →  마지막으로 선착장에 도착  →  배가 떠나며 마무리
```

- 명확한 실패 없음. "해가 완전히 지면" 부드럽게 엔딩(선택적 시간 제한).
- 한 판 = 5~10분.

## 조작 (구현 완료)

| 입력 | 동작 | 상태 |
|---|---|---|
| WASD / 스틱 | 카메라 기준 이동, 이동 방향으로 회전 | ✅ |
| 마우스 / 우스틱 | 3인칭 오빗 카메라 | ✅ |
| Space | 점프 (낮은 턱·발판) | ✅ |
| Shift | 달리기 | ✅ |
| (예정) E | 상호작용 (표지판·사람·물건) | ⬜ |

## 씬 구성

**현재 (프로토타입)**
- 바닥, 벽, 큐브 장애물, 발판 — 이동/점프 테스트용 회색 박스들
- 3인칭 캐릭터(Mixamo Humanoid), Idle/Walk/Run/Jump 블렌드

**1차 확장 (다음 목표)**
- 회색 박스 → 무료 CC0 프롭(부두, 나무통, 벤치, 가로등, 배)으로 교체
- 상호작용 지점 3곳 + 간단한 UI 프롬프트("E 눌러 보기")
- 선착장 트리거 → 엔딩 연출(페이드 + 배 떠나는 소리)

**2차 확장 (여유 되면)**
- 마을 사람 1~2명, 짧은 대사
- 수집 요소(사진/추억 조각) + 개수 표시
- 발소리·파도·바람 앰비언트 사운드

## 기술 메모

- Unity 6.5 / URP / New Input System
- 이동: `CharacterController` (물리 대신 직접 제어 — 정확한 플랫폼 조작)
- 애니메이션: Humanoid 리타게팅 + 1D 블렌드트리(Speed) + Jump 트리거
- 씬/캐릭터/포스트FX/조명 세팅은 전부 `Tools ▸ ...` 에디터 스크립트로 재현 가능
